0.9.5
- 0.9.5
- Clock and timer color / background changes now happen immediately, no need to exit and restart any more
- “Days until” countdown display, up to 3 future dates supported
- Optional extra time zones (5) to display in clock
- Improved selected end time mechanism to avoid having to set, then start the timer
- Preferences remember previous selected end time and default that for easy daily reuse of the same selected end time
- Running timer pause/resume options in addition to stop
- Elapsed time option
- Optional alarms - up to 5, one time, daily selectable repeat interval
- Meteo weather API and geolocation to get current location information, and also allow Meteo API location lookup
- Optional alarms - up to 5, one time, daily selectable repeat interval
- Countdown timer and alarms settings maintain the same color schemes as the clock, and adjust automatically when clock color settings change
- Meteo weather API and geolocation to get current location information, and also allow Meteo API location lookup
- When weather is enabled in the weather menu, it will also be updated dynamically in the clock window below all optional time zones
- Mac .dmg packaging changed to .pkg packaging, with Info.plist included but renamed to Info-plist.txt to avoid conflict with IT teams where Info.plist is considered unapproved for whatever reasons
- Added Linux builds with .deb and .rpm packages, as well as portable app versions
